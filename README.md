# ПАНАКОТА — мобильный сайт кофейни

Онлайн-меню без заказа и оплаты: фото, цены, описания и КБЖУ блюд.

React + TypeScript + Vite + Tailwind CSS v4 + Lucide + React Router.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 — и адрес в локальной сети, чтобы открыть с телефона
npm run build      # сборка в dist/
npm run preview    # проверить сборку
```

Чтобы открыть сайт с телефона, подключите его к той же Wi‑Fi сети и откройте адрес `Network: http://192.168.x.x:5173`, который покажет `npm run dev`.

## Структура

```
src/
  data/menu.ts        — разделы и блюда: название, описание, цена, КБЖУ ('617-46-31-35' = ккал-Б-Ж-У)
  data/cafe.ts        — контакты и ссылки (неподтверждённые поля = null → заглушка в интерфейсе)
  components/         — Header, SideMenu, Chips, DishCard, DishRow, DishImage, Nutrition (КБЖУ)
  pages/              — Главная, Меню, Блюдо, Завтраки, О нас, Контакты, Соцсети, QR, Документы
public/dishes/        — фото блюд, вырезанные из скриншотов меню (без элементов интерфейса)
public/img/           — фото зала для главного экрана
```

## Что заполнить перед показом владельцу

- `src/data/cafe.ts`: адрес, телефон, часы работы. Кнопки «Построить маршрут» и «Позвонить» включатся автоматически.
- Ссылки на Instagram / Telegram (`instagram`, `telegram` в `cafe.ts`).
- `publicMenuUrl` — после публикации сайта; сейчас на экране QR демонстрационный код.
- КБЖУ для 13 позиций, где его нет в исходном меню (вафля с сёмгой, шакшука, греча Верде, каша дня, круассан и все десерты) —
  допишите строку `'ккал-Б-Ж-У'` пятым элементом в `menu.ts`, карточка и кольцо КБЖУ появятся сами.
- Вес порций (`weight` в `menu.ts`) — в исходном меню его нет.
